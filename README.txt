GITHUB PAGES
1. Cipta repository baharu di GitHub.
2. Upload SEMUA kandungan folder ini ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), kemudian Save.
6. GitHub akan memberikan alamat web untuk permainan.

GOOGLE DRIVE
Google Drive sesuai untuk MENYIMPAN atau BERKONGSI pakej ini, tetapi Drive tidak berfungsi sebagai
hos laman statik untuk menjalankan HTML seperti GitHub Pages. Untuk pautan yang terus boleh dimainkan,
gunakan GitHub Pages atau hos web statik lain.

PWA / IKON
Apabila laman sudah menggunakan HTTPS melalui GitHub Pages, Chrome/Edge boleh menawarkan butang
"Pasang Super Muzik", membolehkan laman dipasang seperti aplikasi pada PC atau peranti yang menyokongnya.

RANKING
Ranking Top 10 disimpan dalam localStorage pelayar/peranti. Ranking ini tidak dikongsi antara PC.
Jika mahu satu ranking sekolah yang sama untuk semua murid/peranti, perlu sambungkan permainan kepada
pangkalan data dalam talian seperti Google Sheets + Apps Script, Firebase atau Supabase.
